## 🛡️ El sistema "CERO ERRORES" (úsalo SIEMPRE antes de entregar)

Después de que Claude te genere cualquier trabajo (web, email, Bewerbung, SEO…),
pega este prompt de revisión antes de enviarlo al cliente:

```
Revisa el trabajo anterior como si fueras un control de calidad exigente.
Hazlo en 3 capas y dime qué encuentras en cada una:

1) ERRORES: ortografía, gramática, datos incorrectos, enlaces rotos,
   código que no funciona, contradicciones.
2) PROFESIONALIDAD: tono adecuado al cliente, nada informal de más,
   nada que suene a plantilla genérica.
3) MEJORA: ¿qué cambiarías para que se vea trabajo de nivel senior?

Si todo está perfecto, dilo. Si no, corrígelo y muéstrame la versión final lista.
```

Con esto, aunque el primer borrador tenga un fallo, **nunca sale sin revisar**.

## 💼 PROMPTS POR SERVICIO

### 1. Diseño de webs / Landing pages

```
Rol: Eres un diseñador web y front-end senior.
Objetivo: Crea una [landing page / web] para [tipo de negocio: ej. pizzería, salón de belleza].
Cliente: [nombre y qué vende]
Idioma: [español / alemán / bilingüe ES-DE]
Estilo: moderno, limpio, que cargue rápido, responsive (móvil primero).
Incluye: hero con llamada a la acción, servicios, galería, contacto.
Entrega: HTML + CSS en un solo archivo, listo para publicar.
Al final, aplica el sistema CERO ERRORES.
```

### 2. SEO para clientes

```
Rol: Eres un consultor SEO senior.
Objetivo: Auditoría SEO y plan de acción para [sitio web del cliente].
Idioma del público: [español / alemán]
Analiza: títulos, meta descripciones, encabezados, palabras clave,
velocidad, textos y estructura.
Entrega: (1) lista de problemas ordenados por prioridad,
(2) correcciones concretas listas para aplicar,
(3) 5 palabras clave objetivo con intención de búsqueda.
Al final, aplica el sistema CERO ERRORES.
```

### 3. Bewerbung (solicitud de empleo en alemán)

```
Rol: Du bist Experte für Bewerbungen auf dem deutschsprachigen Arbeitsmarkt.
Ziel: Schreibe ein professionelles Anschreiben für die Stelle [Stellenbezeichnung]
bei [Firma].
Meine Erfahrung: [pega tu experiencia o el enlace a tu cv.html]
Stellenanzeige: [pega el anuncio de la oferta]
Ton: professionell, selbstbewusst, aber nicht übertrieben.
Länge: maximal eine Seite.
Danach: prüfe auf Fehler (Grammatik, Rechtschreibung, Ton) — CERO ERRORES.
```

### 4. Emails a clientes (profesionales)

```
Rol: Eres un asistente de comunicación profesional.
Objetivo: Escribe un email para [cliente] sobre [tema].
Idioma: [español / alemán]
Tono: profesional, cercano, claro. Breve.
Contexto: [qué pasó / qué necesito decir]
Dame 2 versiones: una más formal y una más cercana.
Al final, revisa ortografía y tono — CERO ERRORES.
```

### 5. Gestión / trámites (ej. Kela)

```
Rol: Eres un asistente experto en trámites administrativos.
Objetivo: Ayúdame a [redactar / entender / responder] sobre [asunto: ej. pago de Kela].
Idioma: [español / alemán / finés]
Contexto: [pega el mensaje o la situación]
Explícamelo en simple y, si hay que responder, redacta la respuesta lista para enviar.
Al final, revisa que no falte ningún dato importante — CERO ERRORES.
```

## 🧠 Estructura para prompts perfectos (memorízala)

Cualquier prompt tuyo mejora muchísimo con estas 4 líneas:

```
Rol:      Eres [el experto que necesitas]
Objetivo: Quiero exactamente [el resultado]
Contexto: [cliente, idioma, datos, situación]
Formato:  [email / lista / HTML / PDF / código]
```

## ⚡ Reglas para ser más rápido e inteligente

- **Dicta por voz** en el iPhone en vez de escribir.
- **Una sesión por tema** (webs, SEO, Bewerbung, Kela…) → respuestas más precisas.
- **Siempre pide la versión final lista para entregar**, no un borrador.
- **Aplica CERO ERRORES antes de cada entrega.** Sin excepciones.
- Guarda los trabajos buenos como ejemplo para el próximo cliente.
